# Task Engine

Project tasks support hierarchical work planning for production delivery.

## Capabilities

Tasks include:

- parent task
- subtasks
- assignee
- priority
- status
- labels
- checklist
- due date
- estimated hours
- actual hours

## Statuses

Task statuses:

- Todo
- In Progress
- Blocked
- Review
- Done

Task updates create timeline events and assignment notifications. Labels are scoped per project and tenant.

## Permission Boundary

Task creation and updates require project management permission. Reading tasks is covered by project read permission through the project workspace projection.
