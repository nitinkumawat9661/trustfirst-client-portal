# Mangalam Print Document Requirements

Status: `LOCKED_REQUIREMENT`

The production format must support A4 portrait, multi-page invoices, continuation pages, repeatable headers, buyer/ship-to blocks, invoice/reference fields, structured item tables, HSN, quantity, rate, unit, per-line discount, taxable amount, CGST/SGST/IGST, round-off, amount in words, declarations, footer, and an authorised-signatory area.

Output must use the official Mangalam Sanitary logo and GST-certificate-backed identity. Supplier layouts are structural references only; supplier branding, bank details, and declarations must not be cloned.

Print CSS must repeat table headers, keep totals together where practical, avoid clipped rows, and provide page-safe margins.
