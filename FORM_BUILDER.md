# Form Builder

The form builder provides reusable visual dynamic form contracts.

## Capabilities

Forms support:

- sections
- fields
- validation rules
- conditional logic
- reusable templates
- versioning

Field types include text, textarea, number, currency, select, multi-select, checkbox, date, and file.

## Validation

The platform service validates template structure, including duplicate field keys. Submission validation can be attached by module-specific engines such as the Requirement Engine.
